## 1. アプリの概要と思想

合格ロックは、**本人が自分で決めた目標・習慣**を「やった」と確かめるまで、決済・買い物・SNS などのアプリを Screen Time API（FamilyControls / DeviceActivity / ManagedSettings）でロックする、習慣化・自己管理アプリ。ipa 配布想定。

思想（崩さない）:
- **アプリは試験を作らない・採点もしない。** 何をもって達成とするかは本人が決め、本人が確かめる
- 相棒 AI は、義務ではなく**人生の体験**を勧める伴走者。叱る・管理する存在ではない
- データは**端末内**で完結。外に出るのは、本人が使うと決めた預け金の最小データ（日付とその日の結果）だけ
- **安全の床は絶対**。本人はいつでも逃げられる（下記）

---

## 2. 絶対に守ること（最優先・非交渉）

1. **安全の床は常に生きている。** 緊急解除・一時停止・やめる合図は、どんな状態でも必ず使える。AI 前提の UX にしても、ここだけは AI の成否に依存させない
2. **AI は解除を拒めない・遅らせない・値切らない。** やめる意図を汲んだら、評価や説得をせずに**即座に**解除する。AI が「まだ頑張れる」等で止めることは禁止
3. **解除には AI 非依存の確実な経路を必ず残す。** 端末内 LLM は誤読・失敗しうるので、LLM が動かなくても解除できる決定的な道（完全一致の合言葉判定＋最後の手段の最小操作）を常備する。「ボタンをなくす」は「本人を閉じ込めない」に必ず譲る
4. **お金は自己コミットのまま。** 預けるのは本人の金。未達成分は**本人の Stripe 口座**へ。他人には渡さない。1 日の額に上限（現状 100〜3,000 円）を残す。本番キーは招待コード必須
5. **採点・試験の自動生成はしない。** AI は下書き・提案・伴走に徹し、合否を決めない
6. **プライバシー。** 会話・コミット名・写真は端末外に出さない。預け金サーバーに渡すのは日付と結果のみ
7. **端末内 AI は無検閲のまま。** 内容フィルタや「〜しません」系の制限を足さない（v2.1 で撤去済み）

## 3. いまの状態（v2.1.1・足場）

## 4. v3 でやること（詳細）

### 4.1 配布を「一つの IPA」に（品質はそのまま）

**方針:** 2GiB を超えて分割されている大きい 2 モデルは **IPA に同梱せず、アプリ内ダウンロード/ファイル取り込み**に回す。量子化は下げない（性能最大限を維持）。

やること:
- `AI/models.json` で `gemma4-e2b` と `qwen3.5-4b` の `"ipa"` を **false** にする（CI の同梱対象から外す）。アプリ内 DL（`ModelStore` の HuggingFace からの取得）とファイル取り込みは今までどおり使えるので、オフラインにしたい人は DL 後に使える
- `qwen3.5-2b`（約 1.0GB）と `lfm2.5-1.2b-jp`（約 0.6GB）は **これまでどおり単体 IPA** で同梱（どちらも 2GiB 未満なので 1 ファイル）
- `.github/workflows/build.yml` の **分割ロジック（`>= 2147483648` で part-aa/part-ab にする分岐）を削除**。どの IPA も 2GiB 未満になるので、分割の cat 手順も README から消す
- README の配布表・サイズ・つなげ方の記述を更新。大きい 2 モデルは「アプリ内 DL / ファイル取り込みで入れる（最初から通信なしにしたいとき用）」と明記
- `GoukakuLock-Release.ipa`（約 21MB）/ `-Debug.ipa`（約 33MB）/ `-AI-qwen3.5-2b.ipa` / `-AI-lfm2.5-1.2b-jp.ipa` の 4 本が単体で並ぶ形にする

**受け入れ:** Releases に `*.part-*` が 1 つも無い。gemma4-e2b / qwen3.5-4b はアプリ内 DL で入れて動く。

### 4.2 AI 前提の UX（ボタンを基本なくす）

**方針:** 日常の操作は**会話で完結**させる。画面は「相棒と話す」を中心に据え、タップ前提の操作を減らす。ただし **OS/決済の境界と安全の床**はネイティブ UI を残す。

会話に寄せる操作（例・自然文 → AI が実行、必要なら一言確認してから反映）:
- **チェックイン**: 「英単語おわった」→ 達成を記録してロックを外す
- **コミットの作成・変更**: 「朝に英単語20個やりたい」→ 下書きを出し、確認して登録（変更はこれまでの「ゆるめる変更は翌日から」ルールを尊重）
- **ふり返り**: その週の結果から下書きを提示し、直して保存
- **預け金の開始・額**: 「今週3000円預けたい」→ 用意し、支払いだけネイティブの PaymentSheet
- **やめる/一時停止**: 下記 4.3

**会話にしない（ネイティブを残す）もの:**
- Screen Time の許可（FamilyControls の認可）、iOS の権限ダイアログ
- Stripe PaymentSheet / Apple Pay の支払い画面
- **解除の最後の保険**（4.3 の決定的経路）。これは常に残す
- アクセシビリティ/確実性のための最小フォールバック（VoiceOver、会話が使えない状況）。会話が主、でも代替は必ずある

実装メモ:
- 端末内 AI に **意図分類＋スロット抽出**（check_in / add_commit / edit_schedule / start_deposit / set_amount / reflect / pause / quit / chat …）を担わせ、**実行前に短い確認**を出す（押し間違い・誤読の取り消し 5 分ルールは維持）
- 破壊的・お金が動く操作は、AI の判断だけで確定しない（確認を挟む）。ただし **quit/pause は確認を挟まず即実行**（安全の床）
- 既存の画面（ホーム・体験・記録・設定）は、会話からの深掘り先として残す。全部を消すのではなく「会話が入口」にする

**受け入れ:** 主要操作（チェックイン・コミット作成・ふり返り・預け金開始・やめる）が会話だけで一通りできる。OS/決済/安全の床はネイティブのまま。

### 4.3 やめる＝一文で即解除（AI が汲む・でも拒めない）

**方針:** 「お願いします」「やめさせてください」「参りました」など**一文で、すぐ全解除**。AI は意図を汲むだけで、**解除を止めない**。

設計（安全が最優先なので厳密に）:
- **決定的な合言葉判定を端末内で先に行う**（完全一致＋表記ゆれの正規化）。ここで当たれば **LLM を待たずに即解除**
- それ以外の言い回しは LLM が「やめる意図」を補助的に判定して解除してよい。**ただし LLM は解除を拒否・保留・条件づけできない**。迷ったら「解除する」側に倒す（閉じ込めない）
- 解除後に、相棒は**一文だけ**やさしく添えてよい（例:「おつかれさま。また戻ってきたくなったら呼んで」）。説教・引き止めはしない
- **最後の保険**: 音声/AI が全く使えなくても解除できる最小操作（設定内＋常設の控えめな導線）を必ず残す
- 解除は本人の記録（ログ）に残す。緊急解除・一時停止の既存の床（待機・翌日反映など）とも矛盾させない

**預け金との関係:** やめるのは常に自由。預け金は自己コミット（本人の口座）なので、途中でやめても **他人が得をすることはない**。その週の明日からの分は返金、今日までは既存ルール（結果しだい）。= 「閉じ込めない」と「身銭のコミット」を両立させる。

**受け入れ:** 合言葉の一文で即全解除。LLM を無効化しても解除できる。AI が解除を拒む経路が存在しない（テストで保証）。

### 4.4 AI 機能(既存機能を会話で強める)

端末内で完結。どれも**採点しない**。4 つとも入れる:

1. **コミットの下書き**: ぼんやりした目標（「簿記2級に受かりたい」）から、毎日の具体コミット案を複数提案。本人が選び・直して登録。義務の押し付けはしない
2. **ふり返りの手紙**: その週の達成/未達の結果（`WeeklyReview` の入力項目: うまくいった/難しかった/次の工夫）を AI が下書き。本人が直して保存
3. **緊急解除の対話**: 解除の前に**一度だけ**相棒と短く話す（「いま何に引っぱられてる?」「5分でできる代わりは?」）。**止めはしない**。話した後は必ず解除できる（4.3 と同じ床）
4. **体験の提案**: 進み具合に合わせて、現実の体験・ごほうびを勧める（「3日続いたから、今日は散歩して写真を撮ろう」）。義務ではなく誘い。体験タブと連動

共通:
- モデルごとの会話設定（温度/topP、繰り返し対策、RepetitionGuard）は現状を踏襲
- 失敗時（モデル未DL・生成失敗）は、会話なしでも操作できるフォールバックに静かに落とす

### 4.5 無検閲の端末内 AI（現状維持）

- v2.1 で撤去済みの制限は戻さない。内容フィルタ・ガードレール・「〜しません」系の文言を足さない
- 相棒の口調・人格の作り（「話しかけてくるのはこの人、あなたは相棒」）は維持

### 4.6 決済・本番（自己コミット・自分の口座・ガードは残す）

- **お金の流れは自己コミットのまま**: 本人が預け、達成で返金、未達成分は**本人の Stripe 口座**へ。他人・第三者には渡さない
- **本番対応は維持・強化**: 本番キー（pk_live）対応、**本番は招待コード必須**（URL を知った他人が勝手に支払いを作れないように）、1 日の額の上限、安全の床、自動継続は「その週にアプリを開いたときだけ」——これらは**残す**
- **足してよい**: Apple Pay（PaymentSheet 経由）、領収/控えの表示、額・週数・通貨をサーバー設定で可変、支払い前の最終確認
- **やらない**: 他人へ送金・賞金プール・紹介で儲ける等（資金移動業・景表法・賭博・特商法・消費者契約法の対象になり得るため）。必要になったら実装前に法務を通す前提で別途相談
- 手数料・返金の注意（Stripe 手数料は口座の持ち主負担、返金でも戻らない 等）を README に残す

## 5. 技術メモ

- **構成**: `App/`（SwiftUI、iOS 26 系）、`GoukakuCore/`（判定の芯・Foundation のみ・`swift test`）、`GoukakuAI`/`GoukakuAIMLX`（MLX）、`server/`（Cloudflare Workers・依存なし JS・`node --test`）
- **ロック**: FamilyControls / DeviceActivity / ManagedSettings。拡張 `GoukakuMonitor`/`GoukakuShieldConfig`/`GoukakuShieldAction`、ウィジェット `GoukakuWidget`
- **安全の床**: `GoukakuCore` の LockEngine / Emergency / 一時停止 / やめる合図。v3 でも芯はここに置き、UI から独立させる
- **決済**: `App/Deposit/*`（DepositModel/DepositAPI/Keychain）、`App/Views/Deposit/*`、`server/src/*`。合言葉は iCloud キーチェーン
- **CI**: `.github/workflows/build.yml`（build / ui / model-ipa / report、`v*` タグか Run workflow でリリース）、`server.yml`（テスト＋ deploy）。GitHub Releases は 1 ファイル 2GiB 上限
- **Linux で Swift を回すとき**: `export PATH=/tmp/.../swift-6.3.3-RELEASE-ubuntu24.04/usr/bin:$PATH`

## 7. やらないこと(明示)

- 試験の自動生成・合否採点
- 端末内 AI への内容フィルタ/制限の追加
- 他人への送金・賞金化・紹介報酬などの決済
- 安全の床（緊急解除・一時停止・やめる）を AI の判断で止める/遅らせる実装
- 会話以外の脱出手段を完全に消すこと（最後の保険は必ず残す）

### 補足: この版の肝

v3 の芯は「**閉じ込めないまま、本気にさせる**」こと。
逃げ道（やめる）は一言で開く。だから強制力は「閉じ込め」ではなく「身銭（自己コミットの預け金）」に移す。
AI は入口と伴走で、裁く側にはしない。
