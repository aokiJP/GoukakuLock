# asobi — 端末内AIがつくる、操作できる暇つぶし

SwiftUI / iOS 18以上 / Metal 3対応iPhone。GoukakuLockの「AI・状態・表示を分離」「ローカルモデル専用Downloader」という設計を参考にした独立アプリです。スクリーンタイムや課金の機能は含みません。

## 現在の検証範囲

この成果物は実装済みソースとXcodeプロジェクトです。Linux環境でSwiftのルールエンジンをテストしています。Xcode/iOS SDK/Appleの署名資格がないため、iOSアプリのコンパイル、実機推論、UI操作、署名済みIPAは未検証・未作成です。「インストールして動作確認済みの完成品」ではありません。実機での生成品質、速度、消費電力、メモリ使用量は未計測です。

## 開く・ビルドする

1. MacにXcode 26以降（Swift 6.2以降）を用意します。固定依存mlx-swift-lm 3.32.3がSwift 6.2を要求します。
2. `Asobi.xcodeproj` を開き、Swift Packageの取得を待ちます。最初の依存解決にはネット接続が必要です。
3. `Signing & Capabilities` で自分のTeamと一意なBundle IDを設定し、実機を選んでRunします。
4. `bash scripts/build.sh` はモデル検査・単体テスト・未署名archiveを作ります。
5. `DEVELOPMENT_TEAM=自分のTeamID bash scripts/build.sh signed` はarchive後に署名済みIPAを `build/export/` へ出力します。証明書とプロビジョニングが必要です。書き出し方法は `EXPORT_METHOD=release-testing` 等で変更できます。開発用の既定値は `debugging` です。無料Personal Teamでは通常のIPA配布は制限されるためXcodeから実機実行してください。

証明書・秘密鍵・Apple IDのパスワードはプロジェクトにもチャットにも入れません。`build.sh` のunsigned経路ではインストール可能と誤認するIPAを作りません。

## 使う

起動時に端末内AIで生成を開始します。モデルの読み込みと生成には待ち時間があります。最初の生成が終わる前から遊べるという意味での即時起動は未達です。生成済み体験があれば次回起動時はそれを再開します。

- ボタン／入力／タイマー／得点を使ってその場で遊ぶ。
- シャッフルで途中変更、右下の矢印で再生成。進行中の体験は生成成功まで保持。
- しおりで保存、右上の棚から再開。保存は最大30件。
- 終了後「この先をつくる」で反応を好みに記録し、操作履歴から続編を生成。「違う遊びへ」は好みを下げて別の体験を生成。
- 右上の調整から状況・興味・気分・時間・道具を任意入力。
- 生成中止、生成失敗時の再試行、バックグラウンド時の中断に対応。
- タイマーはシート表示中、生成中、バックグラウンド中に止まります。現実の経過時間ではなく、画面を開いて遊んでいる時間です。

## モデルと推論

`Models/small` は Qwen3-0.6B 4bit、`Models/balanced` は Qwen3-1.7B 4bit。Hugging Faceのmlx-community配布から固定revisionで取得した実データを同梱しています。元モデルのライセンスはApache 2.0。モデルファイルは `Models/manifest.json` のSHA-256で検証します。再取得は `python3 scripts/fetch_models.py`。

8GB以上の物理RAM・通常温度・低電力モードOFFなら1.7B、それ以外は0.6Bを選びます。この閾値は設計値で実機ベンチマークに基づくものではありません。量子化重みをMLX/Metalで実行し、思考出力を無効化。小型設定2200、通常設定3200の生成トークン上限、120秒のストリーム監視、最大2回の構造生成試行。モデル読み込み自体の強制タイムアウトはありません。履歴を無制限にコンテキストへ積みません。

実行時に外部AI APIやモデルダウンロードは使いません。生成は一度に1件。モデルは再利用し、バックグラウンド・メモリ警告でキャンセル後に解放します。生成中はUIスレッドを待たせずactor内で推論。自動生成を無限ループさせないため電池消費を抑えます。

## ルール形式

AIが自由に発明するのは内容、目標、変数、遷移、条件、時間制約、ランダム分岐です。任意の新しいネイティブ機能を生成できるわけではありません。実行可能な操作語彙には意図的な境界があります。

`Experience` → `Node` → `Action`。効果は宣言済み整数変数への加算、条件は加算後の `atLeast` 比較、ランダムは宣言済み移動先から等確率選択。入力は保存され次のAI生成に反映しますが、現在のセッションで内容を自動採点しません。

検証：サイズ48KB、2〜16場面、最大4操作、最大6変数、ID重複・参照先・到達性・終了可能性・数値範囲・タイマーを確認。任意コード、WebView、eval、シェル、外部URL実行はありません。100操作で打ち切り。JSON不正時に固定ゲームへ置き換えたり、偽のAI結果を表示したりしません。エラーと再生成を表示します。

構造の安全性と内容の安全性は別です。プロンプトで座ったままの安全な遊びに限定していますが、自然言語の内容安全性を完全に保証するフィルターではありません。一般公開前には実機品質評価と内容レビューが必要です。

## 保存・依存・構造

Application Support/Asobi/state.jsonへ原子的に保存。端末のデータ保護を使用。現状・保存棚・過去20セッション・タグ好みを保持します。分析SDK、広告、通信API、ログインはありません。

- `Core/Experience.swift`: Codable形式、検証、決定的な実行エンジン
- `App/LocalAI.swift`: MLX読み込み、ローカルトークナイザー、生成と再試行
- `App/Store.swift`: キャンセル、保存、反応と生成コンテキスト
- `App/AsobiApp.swift`: SwiftUI動的UI
- `Tests/EngineTests.swift`: 開始から終了、分岐、タイムアウト、不正入力、保存復元
- `scripts/make_project.py`: Xcodeプロジェクトを再現可能に生成

依存バージョン：mlx-swift-lm 3.32.3 / mlx-swift 0.32.3 / swift-transformers 1.3.4。依存ソース・推移依存は初回XcodeのSwift Package Managerが取得します（全依存ソースのオフライン同梱はしていません）。
